# LMS Management System

A web-based Learning Management System developed using PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript.

## Features
- Admin Dashboard
- Instructor Panel
- Student Panel
- Course Management
- Assignment Submission
- Attendance Management

## Technologies Used
- PHP
- MySQL
- Bootstrap
- HTML/CSS
- JavaScript

## Installation Steps
1. Download or clone the project
2. Move the project folder to `htdocs`
3. Import the SQL database file into phpMyAdmin
4. Configure `db_connect.php`
5. Run the project on localhost using XAMPP
